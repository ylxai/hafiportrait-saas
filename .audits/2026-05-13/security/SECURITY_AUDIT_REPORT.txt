Client Approval Gate (src/lib/auth/options.ts:99-101):

Current State:

- No CORS middleware detected
- Next.js default: same-origin only (secure)
- vercel.json and next.config.ts set security headers but not CORS

Risk Assessment:

- If API needs to be consumed by external clients, CORS must be configured
- Webhook endpoints should remain same-origin or use IP whitelist

Recommendation:
1. Document that API is same-origin only
2. If cross-origin access needed:
   - Add explicit CORS middleware with allowlist
   - Restrict to specific origins (no wildcard *)
   - Use credentials: true only if necessary
3. Keep webhook endpoints same-origin or IP-restricted

Severity: HIGH - Lack of explicit configuration could lead to misconfiguration
if requirements change. Current state is secure but implicit.

6. FILE UPLOAD SECURITY
================================================================================

STATUS: ✅ EXCELLENT

Finding: Comprehensive file upload security with multiple validation layers.

Upload Flow Security:

   ✅ Extension whitelist validation (ALLOWED_EXTENSIONS)

   - Documents: .pdf

   - SVG explicitly excluded (XSS risk)

4. Path Traversal Protection:
   - GalleryId validation: /^(payments\/)?[a-zA-Z0-9_-]+$/
   - Rejects .. sequences

   - R2 key format: uploads/{galleryId}/{uuid}{ext}

   - Per-client quota enforcement (default 10GB, configurable)
   - Atomic quota check via conditional Prisma update
   - Cross-gallery deduplication (same file = one copy)
   - Quota rollback on upload failure

6. Duplicate Detection:
   - SHA-256 hash required at presigned URL generation
   - Unique index on (galleryId, fileHash)
   - Cross-gallery dedup per client (saves storage)
   - Atomic P2002 handling prevents race conditions

Security Gaps: NONE
